How AES-CBC Works
AES (Advanced Encryption Standard) is a symmetric block cipher that encrypts data in 128-bit blocks. In CBC (Cipher Block Chaining) mode, each block is XORed with the previous ciphertext block before encryption, making identical plaintexts produce different ciphertexts. A random IV (Initialization Vector) ensures different output even for the same input and key.
📝
1. Plaintext
Original message, padded to 16-byte block boundary (PKCS#7)
🎲
2. Random IV
16-byte random Initialization Vector generated per encryption
⊕
3. XOR Block
First block XORed with IV; subsequent blocks with previous ciphertext
🔐
4. AES Encrypt
Each XORed block encrypted with the secret key (10/12/14 rounds)
📦
5. Base64 Output
IV + ciphertext concatenated, encoded as Base64 for safe storage
AES Key Sizes
Variant Key Length Rounds Security Common Use

AES-256 32 bytes / 256 bits 14 Maximum TOP SECRET, banking, military
About This Project
The Key Logger with AES Encryption is a Python-based educational cybersecurity project demonstrating how malware can capture and encrypt keystrokes to evade detection. The original project uses pynput to intercept keyboard events and PyCryptodome to encrypt each keystroke using AES-CBC before writing to a log file. A companion decryptor (tkinter GUI) allows authorized recovery using the correct password.

🔑 Original Project

main.py — Runs in background, intercepts keystrokes via pynput.Listener, encrypts each with AES-CBC using key PasswordPassword, appends Base64 ciphertext to log.txt.

🔓 Decryptor

logdecryptor.py — tkinter GUI that prompts for password, reads log.txt, decodes Base64, splits IV from ciphertext, decrypts each line with AES-CBC, writes plaintext to decrypted_text.txt.

📚 Skills Demonstrated

Symmetric encryption (AES-CBC), PKCS#7 padding, IV generation, Base64 encoding, keyboard event interception, GUI programming (tkinter), Python cryptography (PyCryptodome).

⚠️ Ethics & Defense

Understanding how keyloggers work is essential for defense. Defenders use this knowledge to build behavioral detection rules, endpoint monitoring, and educate users about malware threats.
